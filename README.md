# 标途 · 招投标实战训练营

面向初入职场人员的建设工程招投标训练系统。课程采用“共学基础 → 招标组织线／投标实务线 → 双线压测”的路径，目标是帮助学员在授权范围内完成标准项目的可检查交付物。

## 课程组成

- 18 章老师式精讲，合计 240 小时、默认 20 周；每章有工作场景、5 个逐点讲义、记忆框、初学者误区、4 步实训工单、4 栏结构化交付、10 道闭卷题、依据和硬门槛。
- 6 章共学基础、6 章招标组织线、6 章投标实务线；两类岗位先共学，再分别训练。
- 20 周周历和 5 关综合模拟考，要求限时完成交付包、异常处置和导师答辩准备。
- 12 项可追溯官方来源、10 份本地范本与案例，以及宿州平台抓取的 40 条政策目录。

课程中的时间、评分门槛是训练设计，不是法定期限或资格认定。页面自检通过也不代表已经获得独立办理项目的授权；真实项目应按现行规则、组织授权与导师审核办理。

## 开发与验证

使用锁定依赖运行：

```text
pnpm run dev
pnpm run build
node node_modules/typescript/bin/tsc --noEmit
node --experimental-strip-types scripts/verify-course.mjs
```

学习状态只保留在当前浏览器会话，学员可以导出 Markdown。正式试点前应补充账号、持久化进度、导师批注与提交记录；课程及法规条目应由专业人员按版本持续复核。完整路线见 `public/implementation-plan.md`。
